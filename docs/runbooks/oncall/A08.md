# A08 — Web 5xx error rate high

**Sev2.** More than 5% of web requests returned 5xx over 3 minutes, or more than 2% over 10 minutes, with real traffic.

1. Did a deploy just go out? Roll back: [web hotswap rollback](../web-hotswap-rollback.md).
2. `/admin/performance` → error feed: which routes, with trace ids.
3. Is the database or Redis the cause? See [A02](A02.md) and [A06](A06.md).
4. `docker logs <web container> --since 15m | grep -E '"status":5|trace:error'`.
