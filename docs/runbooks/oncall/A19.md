# A19 — Tomorrow's daily puzzles missing

**Sev2.** After 00:15 UTC, the doctrine worker still hasn't confirmed tomorrow's daily puzzles. It only ever creates *tomorrow's*, so if its midnight run failed, **players get no puzzle tomorrow** unless it runs again before then.

1. `docker logs <supervisor container> --since 2h | grep daily_puzzles`: the error.
2. Fix the cause (usually the database), then restart the supervisor. It generates tomorrow's puzzles at startup:
   `docker compose -p rmhstudios-prod --env-file .env.production restart supervisor`.
3. The alarm clears on the next check once the run succeeds.
