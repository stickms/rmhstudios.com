# A19 — Tomorrow's daily puzzles missing

**Sev2.** After 00:15 UTC, `doctrine_puzzle` doesn't hold all six modes for tomorrow's date (the status service reads the table directly). The Node `jobs` worker only ever creates *tomorrow's* (queue `doctrine.daily-puzzles`, cron `0 0 * * *` UTC, plus one run at boot), so if its midnight run failed, **players get no puzzle tomorrow** unless it runs again before then.

1. `docker logs <jobs container> --since 2h | grep -i doctrine` (also `jobs.register_failed` with `queue":"doctrine"` at boot). Check the queue: `SELECT state, count(*), max(completed_on) FROM pgboss.job WHERE name = 'doctrine.daily-puzzles' GROUP BY state;`. A `failed` run carries the error in `output`.
2. Fix the cause (usually the database), then restart the jobs container. It generates tomorrow's puzzles at startup:
   `docker compose -p rmhstudios-prod --env-file .env.production restart jobs`.
3. The alarm clears on the next check once all six modes exist for tomorrow.
