# B06 — Background job stale

**Sev3.** A cadence job hasn't succeeded within its limit: `recap` (20 min), `sahur_activation` (10 min), `streak_sweep` (3 h). The worker may be up but its job failing every run (database, Discord or API errors).

1. `docker logs <supervisor container> --since 1h | grep '"job":"<job>"'` (or `streak-saver:` for streak_sweep).
2. If the worker is down instead, [A11](A11.md) fires too.
