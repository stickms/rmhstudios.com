# D01 — Deploy rollback FAILED

**Sev2.** A web deploy failed its smoke test/bake **and** the automatic
rollback to the previous release also failed. Production may be serving
nothing good.

1. Check the site now. If it's down, [A01](A01.md) will be firing too.
2. Flip back by hand: [web hotswap rollback](../web-hotswap-rollback.md).
3. Read the deploy's log attached to its message in the deploys channel, or
   `/home/rmhstudios/webhook.log` on the VPS.
4. Clears on the next successful deploy.
