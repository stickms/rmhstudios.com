# B03 — Event loop lag

**Sev3.** A service's event-loop delay p99 has been over 500ms for 5 minutes: it is blocking on synchronous work, and every request or socket message on it is slow.

1. `/admin/performance` → which process, and the profiler tab.
2. Common causes: large synchronous JSON/gzip work, a hot loop in a game handler, CPU starvation (check throttling).
