# D04 — Deploy died without reporting

**Sev2.** `deploy.sh` exited after starting but before posting a final
result (an unexpected error, or it was killed). The deploys channel still
shows "deploying".

1. On the VPS: `tail -200 /home/rmhstudios/webhook.log`. The last lines show where it stopped.
2. `docker ps`: is a `web` container healthy? Is anything restart-looping?
3. Re-run the deploy once the cause is understood. Clears on the next successful deploy.
