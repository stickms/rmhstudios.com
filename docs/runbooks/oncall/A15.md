# A15 — Money-path background work failing

**Sev2.** Instances:

- **`A15:economy.<queue>`**: a job on an economy queue (gifts, community goals, wishlist alerts) failed. Coins or gifts may not have been applied.
- **`A15:outbox`**: the oldest undelivered outbox event (webhooks, notifications) is over 10 minutes old.

1. `docker logs <jobs container> --since 30m | grep -i <queue>` for the error.
2. Failed jobs stay in the pg-boss tables: `select id, name, output, completed_on from pgboss.job where state = 'failed' and name = '<queue>' order by completed_on desc limit 5`.
3. Outbox: `select topic, attempts, last_error, created_at from outbox_event where delivered_at is null and dead_at is null order by created_at limit 10`.
4. Fix the cause; pg-boss retries failed jobs per queue policy. Check affected users' balances if gifts failed terminally.
