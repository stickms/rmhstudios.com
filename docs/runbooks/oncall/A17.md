# A17 — Stripe webhook failing

**Sev2.** More than 3 non-2xx responses on `/api/auth/stripe/webhook` in 15 minutes. Stripe retries for a while, then **disables the endpoint**, and subscriptions stop syncing.

1. Stripe dashboard → Developers → Webhooks → the endpoint → recent deliveries: the response body says why.
2. 400 "signature" errors: the webhook signing secret in `.env.production` doesn't match the endpoint's.
3. 5xx: web logs for the handler error (see [A08](A08.md)).
4. After fixing, resend the failed events from the Stripe dashboard.
