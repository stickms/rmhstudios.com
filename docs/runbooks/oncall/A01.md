# A01 — Site down (external check)

**Sev2.** The watchdog's GET of the homepage failed twice in a row (1/min):
non-200, timeout, or the page shell (`id="main-content"`) missing.

1. Is it everyone? Open the site from your phone off Wi-Fi.
2. Is the VPS up? SSH in. If SSH fails too, it's the host or its network:
   check the VPS provider's console/status page and reboot from there.
3. On the box: `docker ps --format '{{.Names}}\t{{.Status}}'`. Is a `web`
   container running and healthy?
4. `curl -sI http://127.0.0.1:7005/api/health` (and `:7015`, the blue/green
   spare). If web answers locally but the site is down, it's Apache:
   `sudo systemctl status apache2`, `sudo apachectl configtest`.
5. Bad deploy? Roll back: [web hotswap rollback](../web-hotswap-rollback.md).

Also see [A02](A02.md), which usually fires alongside when the database is the cause.
