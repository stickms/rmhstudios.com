# B16 — Host health check not running

**Sev3.** The every-minute host check (`rmh-host-check.timer`) stopped checking in, so disk, memory and OOM alerts are blind. If the whole VPS is down, [A01](A01.md) / [A03](A03.md) page instead.

1. `systemctl status rmh-host-check.timer rmh-host-check.service`
2. `journalctl -u rmh-host-check.service -n 50`
3. Not installed? See the header of `deploy/systemd/rmh-host-check.service`.
