# B14 — Process errors spiking

**Sev3.** In the last 10 minutes across Node services: over 20 unhandled promise rejections, any uncaught exception, or over 10 database pool errors. These used to crash processes; now they're caught, counted and logged (`lib/perf/process-guards.ts`).

1. `docker logs <service> --since 15m | grep -E 'unhandled_rejection|uncaught_exception|db_pool_error'`; the line has the error and stack.
2. Pool errors in bulk usually mean Postgres restarted or dropped connections: check [A02](A02.md).
