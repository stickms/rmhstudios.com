# D03 — Deploy failed

**Sev3.** `deploy.sh` stopped with a failure before finishing (the reason is
in the alert: git fetch, image pull, migration, health check…). Production
is unchanged or partly updated.

1. Read the reason and the attached deploy log in the deploys channel.
2. Transient (registry hiccup, network)? Re-run the deploy workflow.
3. Migration failure: do not re-run blindly; read the migration error first.
4. Clears on the next successful deploy.
