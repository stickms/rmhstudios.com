# B05 — Container unhealthy or restarting

**Sev3.** Instances:

- **`B05:<container>`**: Docker reports the container `unhealthy` (its healthcheck is failing).
- **`B05:<container>-restarts`**: it restarted outside a deploy in the last 30 minutes (a crash, or the OOM killer: check [A14](A14.md)).

1. `docker logs <container> --tail 200`: the error before the restart.
2. `docker inspect <container> --format '{{json .State.Health}}'`: the failing healthcheck output.
3. Restart-looping: `docker compose -p rmhstudios-prod --env-file .env.production up -d <service>`; if it keeps looping, roll back the last deploy.
