# A14 — Host memory exhausted / OOM kill

**Sev2.** Two instances:

- **`A14:memory`**: under 5% of host memory available.
- **`A14:oom`**: the kernel OOM killer killed a process in the last 30 minutes (the alert quotes the kernel line, including which process).

1. `docker stats --no-stream`: which container is using the most.
2. `dmesg -T | grep -iE 'out of memory|killed process'`: what was killed. If it was **postgres**, check the site now ([A02](A02.md)).
3. The containers' memory limits add up to more than the box has during a deploy (two web containers); a deploy in progress makes this more likely.
4. Short term: restart the largest offender. Longer term: lower its limit or `mem_reservation`, or a bigger VPS.
