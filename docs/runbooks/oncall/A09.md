# A09 — Web latency high

**Sev2.** Web p95 over 2.5 seconds across the last 10 minutes.

1. `/admin/performance`: slowest routes, event-loop delay, DB average, pool waiting.
2. DB slow? Pool waiting? See [A06](A06.md). Redis restart-looping causes long render stalls: `docker ps | grep redis`.
3. CPU throttled (the admin page shows cgroup throttling)? Something on the box is starving web: check the other containers' CPU.
4. Started with a deploy? Roll back.
