# M02 — Real-user page loads slow

**Sev3.** From real visitors' browsers (web-vitals beacons), on core pages, over 15 minutes:

- **`lcp-core`**: Largest Contentful Paint p95 over 4 seconds.
- **`ttfb-core`**: time to first byte p95 over 1.8 seconds.

1. TTFB high too? The server is slow: see [A09](A09.md) / [A06](A06.md).
2. Only LCP: a heavy asset or client regression, usually right after a deploy. Compare with the deploy time and roll back if it lines up.
3. Thresholds are editable on `/admin/alarms` → Alarm rules.
