# D02 — Deploy auto-rolled back

**Sev2.** A new web release failed its smoke test or 5-minute bake and the
previous release was restored automatically. **Production is fine**; the
commit is not.

1. Read the reason in the alert and the deploy log in the deploys channel.
2. Fix forward with a new commit; the next successful deploy clears this.
3. Two kinds of rollback report here:
   - **web** failed its smoke test or bake → web restored, everything else is on the new release;
   - **hubs / status / supervisor / workers** failed their post-deploy health checks → those
     restored to the previous release (the `:rollback` images), web stays on the new one.
   Migrations from the commit are already applied either way.
