# A03 — Status service stale / VPS heartbeat lost

**Sev2.** Two variants:

- **`A03`**: `status.rmhstudios.com/api/status` is unreachable, or its last
  probe cycle is over 2 minutes old (the prober stalled).
- **`A03:heartbeat`**: the status service stopped checking in with the
  watchdog (every minute). If [A01](A01.md) is firing too, **the VPS itself
  is down**: start there.

1. SSH in. If you can't, the host is down: provider console, reboot.
2. `docker ps | grep status` and `docker logs <status container> --tail 100`.
3. Restart it: `docker compose -p rmhstudios-prod --env-file .env.production up -d status`
   (from the repo checkout). It only affects the status page.
4. Heartbeat variant but the status page looks fine: check `ONCALL_URL` /
   `ONCALL_SIGNING_SECRET` in `.env.production`, and its logs for
   `on-call heartbeat failed`.
