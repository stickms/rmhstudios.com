# A13 / B01 — Disk filling up

**A13 Sev2** at 92% or more, **B01 Sev3** at 85% or more, on `/` or Docker's data directory. Postgres, Docker and logs all share the disk, so a full disk takes everything down at once.

1. `deploy/disk-report.sh` (read-only): where the space went.
2. Usual suspects, safest first:
   - old rollback images: `docker image ls` (deploys keep a couple of SHA tags);
   - build cache: `docker builder prune --filter until=72h`;
   - logs: `/home/rmhstudios/webhook.log`, `journalctl --disk-usage` (`sudo journalctl --vacuum-size=500M`);
   - backup scratch in `/var/tmp`.
3. Never delete anything under the Postgres data directory by hand.
