# A16 — Jobs worker silent

**Sev2.** The `jobs` container stopped checking in (every minute). It runs the background queues **and** the app alarms in this list, so while it's down, those alarms can't fire either.

1. `docker ps | grep jobs`. Running? Restart-looping?
2. `docker logs <jobs container> --tail 200`.
3. Restart: `docker compose -p rmhstudios-prod --env-file .env.production up -d jobs` (from the repo checkout). The web tier runs some work inline while it's down; nothing is lost from the queue.
