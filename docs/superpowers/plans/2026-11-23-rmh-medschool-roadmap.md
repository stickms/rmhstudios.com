# RMH Med Schools — Roadmap after phase 5 (owner decisions of 2026-11-23)

> This is a record, not an implementation plan. Each item below becomes its own plan under `docs/superpowers/plans/` and
> its own PR, written when the item before it has merged. Order is the owner's. The sequence of the first four items
> (phase 6, then items 2-4) is what the owner asked for explicitly; the rest keep the order given.

**Spec:** `docs/superpowers/specs/2026-11-20-rmh-med-schools-design.md` (its §14 phase list is superseded by this order
from phase 6 on). **Where things stand:** phases 1-5 are built (scrapers, public pages, tracker and lists, statistics
and the Forecast tab). Phase 6 (AI Q&A) is in progress in the checkout.

## Standing constraints (every item)

- **Anonymization (spec §6):** no identifier of a person crosses an adapter boundary; the public tier reads aggregates
  or institutional text only; any figure built from tracker rows keeps its floor (k >= 3 for public counts, >= 20
  distinct members for curves and any "people like me" cohort) and the anonymity claim is never written stronger than
  `features/medschools/CLAUDE.md` writes it.
- **Politeness:** one request at a time per host, at least 3 s between requests plus 0-1 s of jitter on every new scrape
  path, a persisted per-host daily request budget (`MedRequestBudget`), robots.txt honoured, `Retry-After` and 429
  backoff with the three-strike halt, the one static User-Agent (`MEDSCHOOLS_USER_AGENT`), page guard (`assertPage`),
  `maxRuntimeMs` equal to the queue expiry, cron owned by the `jobs` timekeeper, a persisted minimum interval. A
  school's own website is not scraped (spec §7); an admin enters what it publishes, with the URL.
- **AI budget split:** `MEDSCHOOLS_AI_MONTHLY_USD` is one cap. Phase 6 reserves a share for Q&A (`MEDSCHOOLS_QA_SHARE`,
  default 25%); the scrape jobs live inside the rest (`scrapeCapUsd`), with SDN, the Admit forums (40%) and any new
  scrape extractor (its own share, default 10% or less) as sub-sums of one ledger. A new model-backed feature names its
  share in its plan and fails closed when the ledger cannot be read.
- **DeepSeek scrape calls run off-peak only** (`isDeepseekPeak`, `lib/ai/deepseek-peak.ts`). Fetching may happen at any
  hour; the model call waits.
- **Delivery:** every item is a branch and a PR, merged only on green CI (`web-ci.yml`), after
  `pnpm check:consistency --base main`, with the typecheck command for this container
  (`GOMEMLIMIT=2GiB GOGC=10 GOMAXPROCS=1 node node_modules/typescript-native/bin/tsc -b --singleThreaded`). Migrations
  are additive.
- **Design:** Steel until item 11. Components are presentational and token-driven (`--site-*`, `t-*`, rows on rules) so
  the redesign restyles them without touching data code. All strings through `t()` in namespace `medschools`.

## Facilitator notes (2026-11-23; owner may override)

- **Shared "school fact" table.** Items 3, 5, 7 and 8 all store dated, sourced, per-program facts about a school (a fee,
  a rolling policy, a prerequisite, a PTE/CTE date). Build one shape once (school, program, kind, cycle, value,
  `sourceUrl`, `checkedOn`, entered-by) rather than four; item 2's `MedSecondaryObservation` is the same idea for text
  and stays its own table because it dedupes by wording.
- **MSAR is excluded** until AAMC's written permission exists; the redesign's stat panels are built so a source can be
  added later without a layout change (item 11).
- **Item 10's premed planning** is private and unscoped beyond the owner's three names; its plan opens with a short
  scope check with the owner rather than assuming more.
- **Every item** names, in its own plan, which of the standing constraints it touches and what its tests pin; the
  anonymization and politeness constraints are test-enforced, not conventions.
