# rmhOS Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A signed-in visitor opens `/rmhOS` and boots a real, rmhOS-branded Linux desktop in the browser tab, with filtered internet access and a home folder that follows their RMH account.

**Architecture:** The v86 x86 emulator (WebAssembly) runs a kernel and Alpine-based root filesystem that we build from pinned upstream sources with our config and patches; nothing binary and no kernel source is committed. A guest agent on the second serial port receives the RMH identity and saves/restores the home folder as a tar through a 9p share; the host stores it in IndexedDB and on S3 through two API endpoints. Internet goes over a Wisp-v1 WebSocket to a new Node hub (`server/rmhos-net`, port 7009) that authenticates a signed ticket and enforces a destination, port, rate and volume policy.

**Tech Stack:** TanStack Start + React 19 (app tier, `AppShell`), `v86@0.5.473`, `ws`, Prisma 7, `lib/storage/s3.server`, vitest, Docker (image build), Linux 6.12.y LTS i386, Alpine 3.22 x86, IceWM.

**Spec:** `docs/superpowers/specs/2026-11-14-rmhos-design.md` — read it before any task.

## Global Constraints

- This is TanStack Start, not Next.js. Read `/CLAUDE.md`, `features/CLAUDE.md` and `app/CLAUDE.md` first.
- No Linux source in the repo (no clone, submodule, subtree, vendored tarball). No built image in git: `public/rmhos-dev/` is git-ignored.
- Feature id is `rmhos`; base path is `/rmhos`; route file is `app/routes/rmhos.tsx`. `/rmhOS` must resolve to it.
- Full-screen app tier only: `AppShell`, `--app-*` tokens from `components/shared/app-theme.css`. No `--site-*` token, no `surface-card` on a `_site` page, no Steel site-tier class inside the app.
- Every user-facing string through `t('key', { defaultValue })` in namespace `c-rmhos`; run `pnpm i18n:extract`; never put a JSX comment directly before a `t()` call.
- Endpoints are `*.contract.ts` + `implement()` + `apiRoute()` in `features/rmhos/api/`; run `pnpm api:routes`. No raw `fetch('/api/…')` string (use `api()` / `apiUrl()` from `@/lib/contract/client`).
- Exact values: guest RAM 640 MB; VGA memory 8 MB; 1024×768×32; uid/gid 1000; home tmpfs 128 MB; quota `100 * 1024 * 1024` bytes of gzipped archive; autosave every 300 000 ms; ticket lifetime 60 s; hub port 7009; hub path `/rmhos-net/`; max 64 streams per connection; allowed ports `80,443,8080,8443`; rate 2 MB/s (`2 * 1024 * 1024` bytes/s); daily cap `2 * 1024 ** 3` bytes; image budgets bzImage ≤ 12 MB, rootfs ≤ 400 MB, state ≤ 80 MB.
- The relay is off unless `RMHOS_NET_ENABLED=1`.
- `pnpm check:consistency` passes before every commit (the agent hook runs it). Stage first, commit separately. Never `--no-verify`.
- Regenerate, never hand-edit: `app/routeTree.gen.ts`, `lib/api/route-table.server.ts`, `docs/_generated/facts.json` (`pnpm facts:generate`), the catalog snapshot (`vitest -u` on `lib/__tests__/catalog-contract.test.ts`).
- Commit messages explain why and end with the session's attribution lines.

## Review Focus

1. **A handle that is not a valid Linux username** (`"Élan.Vital"`, `"9lives"`, `"root"`, empty, 60 characters): the machine still logs in, under a sanitised name. Pinned in Task 1.
2. **A relay destination that resolves to a private address** (`localhost`, `169.254.169.254`, a public name with an A record of `10.0.0.5`, an IPv4-mapped IPv6 literal): the stream is closed with reason "blocked", nothing connects. Pinned in Task 2 and Task 3.
3. **An expired, forged or reused-across-users ticket**: the WebSocket upgrade is refused with 401. Pinned in Task 1 and Task 3.
4. **Two devices saving the same home folder**: the stale device gets a 409 and a choice; no archive is silently overwritten. Pinned in Task 4 and Task 8.
5. **A save larger than the quota, or a tab closed mid-upload**: the previous server archive is intact and the user is told. Pinned in Task 4 and Task 8.

Wire format: host lines `SESSION <user>`, `RESTORE`, `SAVE <nonce>`, `SHUTDOWN`; guest lines `RMHOS READY`, `RMHOS SESSION_OK`, `RMHOS RESTORED`, `RMHOS SAVED <nonce> <bytes>`, `RMHOS POWEROFF`, `RMHOS ERR <code>`. Guest lines without the `RMHOS ` prefix are ignored (kernel noise on the port). Ticket format: `<base64url(userId)>.<expiryMs>.<base64url(hmacSha256(key, "<userId>.<expiryMs>"))>` where `key = hmacSha256(secret, "rmhos-net-ticket-v1")`; compare with `timingSafeEqual`.

```ts
// wisp.ts — Wisp v1: [type u8][streamId u32 LE][payload]
export const WISP = {
  CONNECT: 0x01,
  DATA: 0x02,
  CONTINUE: 0x03,
  CLOSE: 0x04,
} as const;
export const CLOSE_REASON = {
  voluntary: 0x02,
  networkError: 0x03,
  invalid: 0x41,
  unreachable: 0x42,
  timeout: 0x43,
  refused: 0x44,
  blocked: 0x48,
  throttled: 0x49,
} as const;
export type WispPacket =
  | {
      type: 'connect';
      streamId: number;
      streamType: 'tcp' | 'udp';
      port: number;
      host: string;
    }
  | {
      type: 'data';
      streamId: number;
      payload: Uint8Array;
    }
  | {
      type: 'continue';
      streamId: number;
      bufferRemaining: number;
    }
  | {
      type: 'close';
      streamId: number;
      reason: number;
    };
export function decodePacket(buf: Uint8Array): WispPacket | null; // null = malformed
export function encodeData(streamId: number, payload: Uint8Array): Uint8Array;
export function encodeContinue(streamId: number, bufferRemaining: number): Uint8Array;
export function encodeClose(streamId: number, reason: number): Uint8Array;
// policy.ts
export interface RelayPolicy {
  allowedPorts: ReadonlySet<number>;
  maxStreams: number;
  bytesPerSecond: number;
  bytesPerDay: number;
}
export function loadPolicy(env: NodeJS.ProcessEnv): RelayPolicy & {
  enabled: boolean;
};
export type Verdict =
  | {
      ok: true;
      address: string;
      family: 4 | 6;
    }
  | {
      ok: false;
      reason: number;
    };
export function checkConnect(
  p: RelayPolicy,
  req: {
    streamType: 'tcp' | 'udp';
    port: number;
    host: string;
    openStreams: number;
  },
  resolve: (host: string) => Promise<
    {
      address: string;
      family: 4 | 6;
    }[]
  >,
): Promise<Verdict>;
// meter.ts
export class UsageMeter {
  constructor(p: RelayPolicy, now?: () => number);
  /** bytes the user may move right now (token bucket ∩ daily remainder); 0 = wait or capped */
  allowance(userId: string): number;
  consume(userId: string, bytes: number): void;
  dayExhausted(userId: string): boolean;
}
```

`checkConnect` uses `isPrivateIp` from `@/lib/ssrf-guard.server` on **every** resolved address and on IP-literal hosts; all must pass; it returns the first address so the caller connects to what was checked. CONNECT payload layout: `[streamType u8: 1 tcp, 2 udp][port u16 LE][hostname utf8]`. CONTINUE payload: `[bufferRemaining u32 LE]`. CLOSE payload: `[reason u8]`. Before finishing, confirm these byte layouts against the client in `node_modules/v86` (search its build for `wisp`); if the client differs, the client is the authority — fix the codec and the tests and say so in the commit message.
